# In Progress

Beta skills under active iteration. They are excluded from `.claude-plugin/plugin.json`, `docs/`, and the top-level `README.md` until they graduate to `engineering/` or `productivity/`, and they can change or be removed at any time.

Install an in-progress skill directly via `skills.sh` or local symlinking (`./scripts/link-skills.sh`):

```bash
npx skills@latest add mblanc/mb-skills --skill=<name>
```
